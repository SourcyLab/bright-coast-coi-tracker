# Contributing

Keep the tracker usable by opening `index.html` directly and through a static local server. Use vanilla HTML, CSS, and JavaScript with zero runtime dependencies. Keep roster processing and storage in the browser.

- Use only synthetic names, projects, and contacts in fixtures and screenshots. Keep actual rosters, exports, and credentials out of the repository.
- Update both language dictionaries when changing interface copy.
- Add focused tests for changes to parsing, date rules, and calendar serialization.
- Run `node --test` with Node.js 24. Check keyboard navigation, form error feedback, narrow screens, and both color schemes for interface changes.
- Keep wording about recorded dates and request activity. Refer coverage and certificate determinations to the insurance producer.
